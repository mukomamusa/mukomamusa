⚡ Production Deployment Requirements

This is a full-stack Next.js application requiring a Node.js hosting environment:

  • Node.js 20+ - For server-side rendering and API routes
  • Database - SQLite (dev) or PostgreSQL (production)
  • Environment Variables - Payment keys, database URLs, etc.
  • File System - For image uploads and ticket generation
