## 🛠️ Maintenance Commands

### If you need to reset the database:

```bash
cd zambia-bus-booking

# Delete old database
rm database.db

# Re-seed everything
node seed-database.js
node seed-routes.js

# Test it works
node test-db.js
```

### If you need to restart the server:

```bash
cd zambia-bus-booking
npm run dev
```

## 🎯 Quick Actions

### Book a Bus (Customer)
1. Go to homepage
2. Select: Lusaka → Ndola
3. Choose tomorrow's date
4. Click "Search Buses"
5. Select a bus
6. Choose seats
7. Complete booking

### Add a Bus (Company)
1. Login as company
2. Go to "Manage Buses"
3. Click "Add New Bus"
4. Fill in details
5. Save

### Create a Route (Company)
1. Login as company
2. Go to "Manage Routes"
3. Click "Add New Route"
4. Select bus, origin, destination
5. Set times and price
6. Save
